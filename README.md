# Homebrew tap

Apps by ZettaByte, installable with [Homebrew](https://brew.sh).

```sh
brew install joyahmed/tap/panes
brew install --cask joyahmed/tap/trove
```

| App | What it does |
|---|---|
| [Panes](https://github.com/joyahmed/panes) | Snap, stack and grid windows on macOS from the keyboard or by dragging to an edge. |
| [Trove](https://github.com/joyahmed/trove) | A fast file explorer with real tabs, 100,000-file folders and instant search. |
